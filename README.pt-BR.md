# Antigravity Account Ledger

Acompanhe o uso de tokens do Antigravity (modelos Gemini e Claude/GPT) e o detalhamento de custos em USD por conta do Google e intervalo de datas personalizado no Token Monitor.

## Compatibilidade e instalação

Requer o Token Monitor **0.81.0 ou superior**. Importe a pasta do plugin ou o pacote `.tmplugin` em **Configurações → Plugins → Instalar de arquivo**, revise e ative.
