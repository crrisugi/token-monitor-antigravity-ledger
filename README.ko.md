# Antigravity Account Ledger

Token Monitor에서 Google 계정 및 사용자 지정 날짜 범위별로 Antigravity(Gemini 및 Claude/GPT 모델) 토큰 사용량과 USD 비용 내역을 추적합니다.

## 호환성 및 설치

Token Monitor **0.81.0 이상**이 필요합니다. **설정 → 플러그인 → 파일에서 설치**를 통해 플러그인 폴더 또는 `.tmplugin` 패키지를 가져온 뒤 활성화하세요.
