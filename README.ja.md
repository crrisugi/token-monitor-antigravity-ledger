# Antigravity Account Ledger

Token MonitorでGoogleアカウントおよびカスタム日付範囲ごとにAntigravity（GeminiおよびClaude/GPTモデル）のトークン使用量とUSDコスト内訳を追跡します。

## 互換性とインストール

Token Monitor **0.81.0以降**が必要です。**設定 → プラグイン → ファイルからインストール**からプラグインフォルダまたは`.tmplugin`パッケージを読み込んで有効化してください。
